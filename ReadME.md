__Docker UI__

This project is designed to let you manage your docker home server over ssh. This project only used AI to iterate through the arrays and assign that to the variable that displays it in the user interface. It also used some AI to help structure and generate examples to base the project on. Also Micorosft VSCode was used to code this project, so it used a lot of Github Copilot autofill. All of the code that was autofilled was checked by me and was only used in areas with repitive code. If this project gets enough traction, I might try to fix bugs that are given in issues.

__Setup Instructions__
1. To set the app up you first open the .exe, then you enter in your information.
2. If you fill all of the boxes and then hit enter after finishing the IP address you can submit it.
3. Then you have to close the app reopen it.
4. If there is an error press ok and if nothing shows up then press refresh.
5. The error only shows up after creating credentials and launching for the first time.
6. After this there should be no errors and if rthere are errors and you click ok it will show the last updated version of the home lab.
7. You should preferrably put the .exe in it's own directory as it creates files that should not be deleted otherwise there might be errors and you might have to redo setup. Credentials are encrypted.
8. The CMD showing up seems to be a bug, but I cannot find any solutions for it. Also the running indicators are unreliable and for me anyways, only show gray.
